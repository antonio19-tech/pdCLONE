# Installation

## Stable release

To install parkinson_disease, run this command in your terminal:

```sh
uv add parkinson_disease
```

Or if you prefer to use `pip`:

```sh
pip install parkinson_disease
```

## From source

The source files for parkinson_disease can be downloaded from the [Github repo](https://github.com/memzero/parkinson_disease).

You can either clone the public repository:

```sh
git clone https://github.com/memzero/parkinson_disease
```

Or download the [tarball](https://github.com/memzero/parkinson_disease/tarball/main):

```sh
curl -OJL https://github.com/memzero/parkinson_disease/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd parkinson_disease
uv sync
```
